# 🤖 Alura Agente - Asistente Virtual RAG

Este repositorio contiene la implementación de un agente inteligente basado en **RAG (Retrieval-Augmented Generation)** desarrollado para consultar la documentación técnica oficial de **Santos Pegasus Soluciones**.

---

## 🛠️ Tecnologías Utilizadas
* **Python 3.11+**
* **Streamlit** (Interfaz de usuario)
* **LangChain** (Framework para orquestación de RAG)
* **FAISS** (Base de datos vectorial)
* **HuggingFace Embeddings** (`all-MiniLM-L6-v2`)
